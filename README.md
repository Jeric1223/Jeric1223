백엔드 개발자입니다. IoT 센서 데이터를 다루는 일을 하고 있고, 요즘은 AI 에이전트가 실제로 일하게 만드는 도구를 만들고 있습니다.

## 요즘 만드는 것

### [tossinvest-mcp](https://github.com/Jeric1223/tossinvest-mcp)

Claude에서 토스증권 계좌로 국내·미국 주식을 조회하고 주문하는 MCP 서버입니다. 시세, 호가, 체결, 차트, 투자자 수급, 보유 종목, 환율을 읽고, 사용자 확인 절차를 거쳐 일반 주문과 SINGLE·OCO·OTO 조건주문을 등록합니다. 돈이 오가는 도구라 주문 전 확인 절차를 프로토콜에 넣었고, 에이전트가 혼자 체결하지 못합니다.

TypeScript, [npm](https://www.npmjs.com/package/@soehd0889/tossinvest-mcp) 배포 (월 500+ 다운로드)

### [my-claude-skills](https://github.com/Jeric1223/my-claude-skills)

반복 작업의 순서, 형식, 검증 기준을 `SKILL.md`로 문서화한 Claude Code 플러그인 마켓플레이스입니다. 한 번 쓰고 버리는 프롬프트 대신 다음에도 같은 품질이 재현되게 만드는 것이 목적입니다. [등록된 스킬 둘러보기](https://my-claude-skills-site.vercel.app) (사이트: [my-claude-skills-site](https://github.com/Jeric1223/my-claude-skills-site))

### [공공자전거 최적 경로 찾기](https://github.com/Jeric1223/PUBLIC-BIKE-ROUTE-FINDER)

대전 타슈와 서울 따릉이의 가까운 정류소를 찾고 경로를 안내하는 PWA입니다. 제가 쓰려고 만들었고, 서버 없이 GitHub Actions와 GitHub Pages만으로 운영해 서버 비용이 0원입니다.

React, TypeScript, OpenLayers · [데모](https://jeric1223.github.io/PUBLIC-BIKE-ROUTE-FINDER/)
